Manual do Robô Polymarket

Guia passo a passo para configuração e operação

1. Como Utilizar as Funções do Robô

O painel de controle permite alternar entre os modos de operação do robô em tempo real.

  • Botão Simulation (Laranja): O robô opera usando dinheiro falso (dinheiro de mentira) para validar a eficácia da estratégia sem risco. Os resultados vão para o quadro de P&L Simulado.
  • Botão Live Trading (Roxo): O robô conecta diretamente na Polymarket com o seu dinheiro de verdade usando as chaves inseridas nas configurações. Atenção: Apenas ligue se tiver certeza da configuração!
  • Botão STOP Geral (Vermelho): Freio de emergência. O robô para de tomar decisões imediatamente.
Perfis de Estratégia: Nas configurações (⚙️), você pode escolher a agressividade do robô.
• Bola de Neve: Conservador. Entra faltando 2 min. Multiplica 20% do capital acumulado.
• Sniper Antecipado: Retorno médio. Entra faltando 7 min. Retorno de 60%+.
• Reversão: Agressivo. Entra faltando 12 min contra a manada. Retorno de até 500%.

2. Como Criar Conta na Polymarket

Se você ainda não possui conta para depositar fundos:

  1. Acesse o site oficial: polymarket.com.
  2. Clique em Sign Up (ou Log In) no canto superior direito.
  3. Você tem duas opções fáceales:
    • Criar via Email (Proxy Wallet): A forma mais fácil. Digite o e-mail, e a Polymarket criará uma carteira automática vinculada a ele.
    • MetaMask / Rabby: Se você já usa carteiras Web3, clique em "Connect Wallet" para entrar diretamente pela sua extensão.
  4. Deposite USDC na rede Polygon para ter saldo para operar.

3. Pegando suas Credenciais da API da Polymarket

O robô precisa das suas chaves de API para comprar e vender no seu lugar (mesmo usando MetaMask ou Email).

  1. Acesse a Polymarket e faça o login.
  2. Clique no ícone de Perfil (canto superior direito) e vá em Settings.
  3. Role a página até encontrar a seção API Keys ou Developer Settings.
  4. Clique em Create New Key (Criar nova chave).
  5. A plataforma vai mostrar três códigos importantes que só aparecerão uma única vez na tela:
    • API_KEY
    • API_SECRET
    • API_PASSPHRASE
  6. Copie os três e cole dentro da engrenagem (⚙️) no seu Dashboard.

4. Pegando a Chave Privada da Carteira (MetaMask)

Para enviar ordens para o blockchain, o robô precisa assinar criptograficamente com a chave privada da sua carteira que contém o saldo.

  1. Abra a extensão da MetaMask no seu navegador.
  2. Clique no ícone de três pontinhos (⋮) no canto superior direito.
  3. Selecione Detalhes da Conta (Account Details).
  4. Clique no botão Mostrar Chave Privada (Show Private Key).
  5. Digite sua senha da MetaMask para revelar.
  6. Copie a longa sequência hexadecimal gerada.
ATENÇÃO DE SEGURANÇA MÁXIMA
A sua Chave Privada (Private Key) é a dona do seu dinheiro. Quem possui essa chave pode transferir todos os seus fundos. NUNCA entregue isso a terceiros. Ao colocar essa chave na engrenagem do Dashboard, o nosso painel criptografa a chave localmente no banco de dados interno da sua própria máquina/VPS (Redis) e não envia para nenhuma nuvem ou banco de dados externo. O robô puxa ela direto do banco de dados fechado para assinar o trade na hora do ataque.
